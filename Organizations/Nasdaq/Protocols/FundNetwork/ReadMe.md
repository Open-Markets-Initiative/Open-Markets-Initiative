## Nasdaq Fund Network


Nasdaq Fund Network (NFN), operated by Nasdaq Information, LLC, which collects price and earnings information for U.S. investment companies and disseminates it on the NFN Data Service.


### Protocols


| Protocol | Type | Note |
| --- | --- | --- |
| [DataService](DataService.md) | MarketData | NFN Data Service |
