Overview


NASDAQ OMX offers many of its direct data feed products in a UDP/IP protocol option. Please refer to NASDAQ OMX Global Data Products - Direct Data Feeds page for product description and technical interface documentation for the U.S. based products.

As a service to network providers, NASDAQ OMX maintains a consolidated list of IP addresses for its UDP/IP services. Please note that NASDAQ OMX reserves the right to modify this IP address information as needed for network and operational reasons.
