## Philippine Stock Exchange Equities


Philippine Stock Exchange equities market, run on the Nasdaq X-stream trading system and published through the ITCH Total View, Basic with Last Sale, News and Index market data feeds.


### Protocols


| Protocol | Type | Note |
| --- | --- | --- |
| [BasicWithLastSale](BasicWithLastSale.md) | MarketData | Pse Equities Itch Basic With Last Sale |
| [Index](Index.md) | MarketData | Pse Equities Itch Index |
| [News](News.md) | MarketData | Pse Equities Itch News |
| [TotalView](TotalView.md) | MarketData | Pse Equities Itch Total View |
