## AquisStockExchange Tick: Aquis Stock Exchange tick reference data file

Aquis Stock Exchange daily tick reference file, tab delimited: each tick table's price levels and tick intervals, named as the security file's tick names.

### Overview

The first line is a header row naming the columns, each following line one row of the file, its columns separated by a tab (AQSE Reference Data Specification, section 3.2).

### Transport

Daily files, available from 04:00 on the Aquis FTP/SFTP service to connected members (tick-<yyyymmdd>.csv).

### Key Characteristics

- **Reference files** - One file per day, not a live feed
