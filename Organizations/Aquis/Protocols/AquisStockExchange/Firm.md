## AquisStockExchange Firm: Aquis Stock Exchange firm reference data file

Aquis Stock Exchange daily firm reference file, tab delimited: each firm's ID, name, BIC, type, market maker group and the trader IDs and CompIDs that link it to the market data streams.

### Overview

The first line is a header row naming the columns, each following line one row of the file, its columns separated by a tab (AQSE Reference Data Specification, section 3.3).

### Transport

Daily files, available from 04:00 on the Aquis FTP/SFTP service to connected members (firm-<yyyymmdd>.csv).

### Key Characteristics

- **Reference files** - One file per day, not a live feed
