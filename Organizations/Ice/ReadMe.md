## Intercontinental Exchange

Intercontinental Exchange (ICE) is an American company formed in 2000 that operates global financial exchanges and clearing houses and provides mortgage technology, data and listing services.

> [!IMPORTANT]
> **ICE protocol specifications are not published in this repository.** Intercontinental Exchange distributes its wire-level interface specifications — the iMpact multicast market data feed, Binary Order Gateway order entry, and the connectivity manuals and message references that accompany them — to participants and authorised vendors under ICE's market data and API agreements. Those documents are licensed and may not be disclosed or redistributed. No ICE specification document is held in this repository or will be published here. Access requests should be directed to ICE: https://www.ice.com
