## National Equities Exchange and Quotations


National Equities Exchange and Quotations trading system for shares of unlisted public companies. Market data is published through the market quotation gateway (BJQG) that it shares with the Beijing Stock Exchange, under interface specifications the two issue jointly.


### Protocols


| Protocol | Type | Note |
| --- | --- | --- |
| [MulticastMarketData](MulticastMarketData.md) | MarketData | Neeq Multicast Market Data |
| [OrderEntry](OrderEntry.md) | OrderEntry | Neeq Order Entry |
| [TcpMarketData](TcpMarketData.md) | MarketData | Neeq Tcp Market Data |
