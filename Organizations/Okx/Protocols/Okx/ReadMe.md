## OKX


OKX crypto exchange trading spot, margin, perpetual swaps, futures and options on one venue, with JSON and Sbe WebSocket APIs.


### Protocols


| Protocol | Type | Note |
| --- | --- | --- |
| [MarketData](MarketData.md) | MarketData | Okx WebSocket Market Data |
| [Private](Private.md) | DropCopy | Okx Sbe WebSocket Private Orders and Fills |
| [Trade](Trade.md) | OrderEntry | Okx Sbe WebSocket Order Entry |
