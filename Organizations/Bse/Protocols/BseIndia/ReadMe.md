## BSE India


BSE's trading venue covering all product segments. The Enhanced Order Book Interface is published for every BSE product rather than per segment, so equities, equity derivatives, currency derivatives, and commodities share one feed.


### Protocols


| Protocol | Type | Note |
| --- | --- | --- |
| [Emdi](Emdi.md) | MarketData | Enhanced Market Data Interface |
| [EmdiSnapshot](EmdiSnapshot.md) | MarketData | Enhanced Market Data Interface Snapshot |
| [Eobi](Eobi.md) | MarketData | Enhanced Order Book Interface |
| [Eti](Eti.md) | OrderEntry | Enhanced Trading Interface |
| [Mdi](Mdi.md) | MarketData | Market Data Interface |
