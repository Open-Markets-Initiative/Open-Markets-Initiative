## EexDerivatives Mdi: EEX T7 Netted Market Data

Netted price level market data for the EEX derivatives markets on T7, encoded as Fix messages in Fast 1.2 on Ip multicast.

### Overview

EEX trades its derivatives on Deutsche Boerse's T7, and names Market Data Interface (Mdi) among T7's public market and reference data interfaces, whose changes are described in the Eurex system documentation (EEX Customer Information, T7 Release 14.1 Final Release Notes).

### Transport

Ip multicast on the Deutsche Boerse T7 network, in EEX's own multicast group ranges (N7 Network Access Guide).
