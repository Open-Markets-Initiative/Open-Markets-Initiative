## EexDerivatives Eobi: EEX T7 Order Book Market Data

Binary market data feed publishing the full unnetted order book and trade events for the EEX derivatives markets on T7 via Ip multicast.

### Overview

EEX trades its derivatives on Deutsche Boerse's T7, and names Enhanced Order Book Interface (Eobi) among T7's public market and reference data interfaces, whose changes are described in the Eurex system documentation (EEX Customer Information, T7 Release 14.1 Final Release Notes).

### Transport

Ip multicast on the Deutsche Boerse T7 network, in EEX's own multicast group ranges (N7 Network Access Guide).
