## EexDerivatives Rdi: EEX T7 Reference Data

Reference data for the products and instruments of the EEX derivatives markets on T7, encoded as Fix messages in Fast 1.2 on Ip multicast.

### Overview

EEX trades its derivatives on Deutsche Boerse's T7, and names Reference Data Interface (Rdi) among T7's public market and reference data interfaces, whose changes are described in the Eurex system documentation (EEX Customer Information, T7 Release 14.1 Final Release Notes).

### Transport

Ip multicast on the Deutsche Boerse T7 network, in EEX's own multicast group ranges (N7 Network Access Guide).
