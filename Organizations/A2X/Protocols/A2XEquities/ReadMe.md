## A2X Equities


A2X Markets is a licensed South African stock exchange providing a secondary listing venue for equities, running on Aquis Exchange matching engine and market data technology.


### Protocols


| Protocol | Type | Note |
| --- | --- | --- |
| [InwardListedPrices](InwardListedPrices.md) | ReferenceData | A2X Markets inward listed prices reference data file |
| [OrderEntry](OrderEntry.md) | OrderEntry | A2X Markets Fix 4.2 Order Entry and Trade Reporting |
| [Rtmdf](Rtmdf.md) | MarketData | A2X Markets real time market data |
| [Security](Security.md) | ReferenceData | A2X Markets security file reference data file |
| [SecurityComma](SecurityComma.md) | ReferenceData | A2X Markets security file comma delimited reference data file |
| [SecurityExtra](SecurityExtra.md) | ReferenceData | A2X Markets minimum large in scale size reference data file |
| [SecurityExtraComma](SecurityExtraComma.md) | ReferenceData | A2X Markets minimum large in scale size comma delimited reference data file |
| [SecurityPlus](SecurityPlus.md) | ReferenceData | A2X Markets security plus reference data file |
| [Snapshot](Snapshot.md) | MarketData | A2X Markets snapshot market data |
| [Tick](Tick.md) | ReferenceData | A2X Markets tick reference data file |
| [TickComma](TickComma.md) | ReferenceData | A2X Markets tick comma delimited reference data file |
| [TradingProtocol](TradingProtocol.md) | OrderEntry | A2X Markets binary order entry (ATP) |
