## Nairobi Securities Exchange Equities


The Nairobi Securities Exchange equity trading system, whose market data is published over MITCH: a Real-Time multicast channel from a main and a backup site, recovered through Tcp Replay and Snapshot channels per market data group.


### Protocols


| Protocol | Type | Note |
| --- | --- | --- |
| [RealTime](RealTime.md) | MarketData | Nairobi Equities Real Time |
| [Replay](Replay.md) | MarketData | Nairobi Equities Replay |
| [Snapshot](Snapshot.md) | MarketData | Nairobi Equities Snapshot |
