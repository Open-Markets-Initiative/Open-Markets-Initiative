## Idem Order Entry: Sola Fix Order Entry

Fix 4.2 order entry interface to the Sola derivatives trading platform of the Italian Derivatives Market, for submitting, modifying and cancelling orders and cross orders, requesting quotes and defining strategies; market making requires the native Sail protocol instead.

### Transport

Tcp Fix 4.2 session for reliable ordered delivery of order entry, quote request, security definition and execution report messages.
