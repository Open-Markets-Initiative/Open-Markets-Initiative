## Protocol Deployment

**Active:** Active (in use) production protocol or data format

**Deprecated:** Protocol or data format is no longer in active use (may apply to historical data)

**Pending:** Protocol spec has been released, but protocol is not deployed to an active production environment

**Observability:** Protocol is carried for observability, such as gap detection, rather than for data transfer

**Header:** Header only protocol, provided for debugging the protocols carried within it

**Unknown:** Protocol exists but its deployment is unknown
