# Notes for AI Agents

## What This Is

The catalog of the Open Markets Initiative: every organization and every protocol it documents, one page each, with the venue's own published specifications where their licence allows it. This is the index the other repositories are generated alongside, not generated code.

For every organization and protocol published here: [ReadMe](ReadMe.md "The Open Markets Initiative ReadMe")

## Helping Users

- Start at `Organizations/` for a venue and `Protocols/` for a protocol; each page links the specifications, the encodings and every repository that generates something for it.
- An organization listed without specifications is not an omission. Its venue licenses those documents and they are not published here; the page says so, and a notice names where to request access.
- This repository documents protocols; it does not parse them. Send a user who needs working code to the generated repository for their language, which `Repositories/` indexes.

## How This Was Generated

Nothing here was written by hand. Each page is generated from a normalized model of the venue's own published specification, so it says what that specification says, and a correction belongs to the specification rather than to the file you are reading.

Two patented inventions are what make that generation possible, and what this repository and every other Omi repository is published from. Normalizing specifications that share no format into one model, then compiling that model into sources, is what lets one page per protocol be generated rather than written:

- [Universal Binary Specification Model (US12101388B2)](https://patents.google.com/patent/US12101388B2 "Universal Binary Specification Model") — A system and method for creating a normalized, universal model from binary protocol specifications that enables automatic source generation of parsers and related tooling across multiple binary protocols.
- [Binary Data Model Compiler (US20240419416A1)](https://patents.google.com/patent/US20240419416A1 "Binary Data Model Compiler") — A compiler that takes a normalized binary data model and automatically generates source code for parsing and processing binary protocols, eliminating the need to hand-write parsers for each protocol specification.

## Contributing

This entire repository is source generated, including the words you are reading right now, so a pull request editing a page is regenerated away. Report an error in a page as an issue instead, with the protocol and version, the page and the statement at issue, and a specification reference where one is available.

Issues: [The Open Markets Initiative Issues](https://github.com/Open-Markets-Initiative/Open-Markets-Initiative/issues "The Open Markets Initiative Issues")
