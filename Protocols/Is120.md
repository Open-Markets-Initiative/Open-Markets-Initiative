## Is120: Sse Market Data Gateway BINARY interface

The BINARY interface specifies the mechanism and data formats for transmitting market data through the Shanghai Stock Exchange Market Data Gateway.

### Overview

All numeric fields are encoded in big endian byte order.

A char[x] field is a string with a maximum length of x bytes, where x is greater than zero. When the maximum length is greater than the actual length, the string is right padded with spaces. Strings use GBK encoding.

An int or uint type gives the integer width, for example uint32 is a 32 bit unsigned integer and int64 is a 64 bit signed integer. Nx and Nx(y) are used with int and uint to give the length (precision) of the business field the integer represents. Nx is an integer of at most x digits; Nx(y) has at most x digits, of which the last y are the fractional part.

### Transport

The user market data system receives streaming market data from the gateway over TCP. Both sides send Heartbeat messages during idle periods to monitor the session.

### Key Characteristics

- **Big endian** - All numeric fields are encoded in big endian byte order
- **Gbk text** - Strings are GBK encoded with a maximum byte length and right padded with spaces
- **Scaled integers** - An Nx(y) integer has at most x digits, of which the last y are the fractional part
